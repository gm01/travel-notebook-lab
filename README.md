# Travel Notebook — 프런트엔드 실습

여행 정보를 주제로 데이터 구조화, 반응형 화면 구성, 상태 저장, 정적 사이트 배포를 연습한 개인 학습 프로젝트입니다. 서비스 운영보다는 자료를 정리하고 웹 인터페이스로 구현하는 과정에 초점을 두었습니다.

## 실습한 작업

- **데이터와 화면 분리:** 일정·숙소·장소·준비 항목을 TypeScript 데이터로 정리하고 React 컴포넌트에서 재사용했습니다.
- **반응형 UI 구성:** CSS Grid와 미디어 쿼리로 모바일·데스크톱 레이아웃을 구성하고 색상·타이포그래피·간격을 통일했습니다.
- **체크리스트 상태 저장:** React 상태와 localStorage를 사용해 같은 브라우저에서 체크 상태가 유지되도록 구현했습니다.
- **외부 자료 활용:** Notion에 정리한 자료를 검토해 필요한 항목을 수동 반영하고, 날짜와 인원 조건을 담은 숙소 검색 링크를 생성했습니다.
- **기본 접근성 및 인쇄 지원:** 시맨틱 마크업, 체크박스 레이블, 건너뛰기 링크와 인쇄용 스타일을 적용했습니다.
- **검증과 배포:** Node.js 테스트로 일정의 연속성·숙박 수·검색 링크·서버 렌더링을 확인하고 GitHub Actions로 정적 사이트 배포를 자동화했습니다.

## 사용한 도구

| 도구 | 사용 목적 |
| --- | --- |
| React 19 · TypeScript | 컴포넌트 작성과 데이터 모델링 |
| CSS · localStorage | 반응형 스타일과 브라우저 내 상태 저장 |
| Vite · vinext | 개발 서버, 빌드 및 서버 렌더링 구성 |
| Notion | 참고 자료와 기획 메모 정리 |
| Node.js Test Runner · ESLint | 동작 검증과 코드 점검 |
| Git · GitHub Actions · GitHub Pages | 변경 이력 관리와 정적 사이트 배포 |
| OpenAI Sites | 별도 사이트 게시 환경 |

## 프로젝트 구성

- `app/trip-data.ts`: 화면에 사용하는 데이터와 검색 링크 생성 함수
- `app/page.tsx`: 페이지 컴포넌트와 체크리스트
- `app/globals.css`: 공통 스타일, 반응형 및 인쇄 레이아웃
- `pages-src/`: GitHub Pages용 진입점
- `tests/rendered-html.test.mjs`: 데이터와 렌더링 검증
- `.github/workflows/pages.yml`: 빌드·배포 자동화

## 실행 및 검증

Node.js 22.13 이상이 필요합니다.

```bash
npm ci
npm run dev
```

```bash
npm test             # 빌드 후 데이터·렌더링 테스트
npm run lint         # 코드 점검
npm run build:pages  # GitHub Pages용 정적 빌드
```

## 구현 범위

Notion API를 통한 자동 동기화나 예약·결제 기능은 구현하지 않았습니다. 외부 자료는 수동으로 반영하며, 체크리스트는 기기 간 공유되지 않습니다. 숙소 링크는 검색 편의를 위한 것으로 실시간 가격이나 예약 가능 여부를 보장하지 않습니다.

이 README는 구현 과정 중심의 소개입니다. 소개 문구 변경은 저장소·사이트의 접근 권한이나 기존 커밋 이력을 변경하지 않습니다.
